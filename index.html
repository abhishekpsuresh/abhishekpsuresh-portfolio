01Who I am

Curious by nature, security-minded by design. I’m a BCA student passionate about cybersecurity, infrastructure security, cloud technologies, and building secure real-world applications.

My foundation is a Computer Applications degree at Marian College Kuttikkanam, where cloud security, ethical hacking and IoT security shape how I look at every system: each service, device and login is something to understand before it can be protected. I learn best by doing, so classroom ideas quickly become labs, scans, small applications and containers that I can break, fix and explain.

Beyond the classroom, hands-on industry training has taken me through AWS and Azure environments, Linux server hardening and automated deployments with Ansible and CI/CD, while a Microsoft Cybersecurity Analyst certification added the enterprise view of threats, identity and compliance. A top-four finish in a network design and implementation event, and a bus-booking platform built from scratch, showed me how design choices in networks and code decide how secure a system really is.

Right now I am aiming for roles in cloud security, penetration testing and security operations, where I can keep learning on real infrastructure while building the habits of careful testing and clear reporting.

    09How I work

    A repeatable path from scope to findings.

    01

    Scope

    Define what is being assessed and what is out of bounds before touching anything.

    02

    Map

    Identify hosts, services, identities and data flows so the attack surface is visible.

    03

    Test

    Probe with hands-on tooling and validate each finding rather than trusting a scan.

    04

    Document

    Record evidence, impact and steps to reproduce so a finding can be understood and fixed.

    05

    Fix & verify

    Recommend controls, then re-test that they actually hold.
